Plakat Kompass: Downloads

Die App für Linux und Windows. Mehr zur App auf plakat-kompass.de.

Linux (Mint, Ubuntu, Debian)

Für Linux Mint 22, Ubuntu 24.04 und neuer sowie Debian 13.

Paket (.deb) herunterladen
  1. Die Datei .deb herunterladen und mit einem Doppelklick öffnen.
  2. In der Software-Verwaltung auf „Installieren“ klicken.
  3. Fertig. Updates kommen danach mit der normalen Systemaktualisierung.
Im Terminal geht auch: sudo apt install ./plakat-kompass_*.deb
