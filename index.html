Plakat Kompass für den Computer

Für die Verwaltung am Schreibtisch. Für Linux, Windows folgt.

Bitte zuerst lesen: nur für die Verwaltung

Die Computer-Version ist zum Ansehen, Auswerten und Bearbeiten gedacht. Wichtige Grundfunktionen der App fehlen hier, zum Beispiel der GPS-Standort. Er funktioniert am Computer nicht.

Plakate lassen sich hier nur von Hand über das Adressfeld eingeben.

Zum Plakatieren und Kontrollieren unterwegs nehmt bitte die App auf dem Handy.

Linux

Linux Mint 22, Ubuntu 24.04 und neuer, Debian 13

Paket (.deb) herunterladen
  1. Die Datei mit einem Doppelklick öffnen.
  2. In der Software-Verwaltung auf „Installieren“ klicken.
  3. Fertig. Updates kommen danach mit der normalen Systemaktualisierung.

Im Terminal geht auch: sudo apt install ./plakat-kompass_*.deb
